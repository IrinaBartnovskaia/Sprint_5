# Sprint_5
UI-тесты Selenium для Stellar Burgers

Набор автотестов на Selenium + Pytest для сайта
https://stellarburgers.nomoreparties.site/.

Покрыто:

Регистрация (позитив/негатив короткий пароль)

Вход из разных точек (главная, личный кабинет, форма регистрации, форма восстановления пароля)

Навигация в личный кабинет и обратно (по «Конструктор» и по логотипу)

Раздел «Конструктор»: переключение вкладок Булки / Соусы / Начинки (параметризованный тест)

Технологии

Python 3.10+ (у тебя 3.13 — ок)

Selenium 4.x

Pytest 7/8

Faker (генерация тестовых данных)
